# トレーニング記録アプリ

会員が自宅トレーニングをした日にチェックをつけ、管理者が全員の進捗(履歴・グラフ)を確認できるWebアプリです。
外部パッケージ不要、Node.jsだけで動きます(`npm install` は不要です)。

## 必要なもの

- Node.js (v18以上を推奨。 https://nodejs.org からインストールできます)

## 使い方(自分のPCで動かす場合)

1. このフォルダをPCの好きな場所に置く
2. ターミナル(またはコマンドプロンプト)でこのフォルダに移動する

   ```
   cd training-tracker
   ```

3. 管理者アカウントを作成する(初回のみ)

   ```
   npm run seed
   ```

   実行すると次のログイン情報が作られます。

   - ユーザー名: `admin`
   - パスワード: `admin123`

   **ログイン後、必ずパスワードを変更してください。**

4. サーバーを起動する

   ```
   npm start
   ```

5. ブラウザで `http://localhost:3000` を開く

## 使い方(会員・管理者それぞれ)

- 管理者としてログイン → 管理者ダッシュボード
  - 会員を追加(名前・ユーザー名・初期パスワードを入力)
  - 全会員の「今週の実施回数」「今月の実施回数」「目標達成 連続月数」「連続日数」「累計」「最終実施日」を一覧表示
  - 特典の受け取り対象者には「🎁 特典を渡す」ボタンが表示される。渡したら押すと記録される
  - 会員名をクリックすると、その人の履歴グリッド・週次グラフ・月次グラフ・特典状況を詳しく表示
  - 会員のパスワード再設定、削除も可能
  - データのバックアップをダウンロード / バックアップファイルから復元も可能
- 会員としてログイン → マイページ
  - 「トレーニング完了をチェック」ボタンで今日の記録をつける(もう一度押すと取り消し)
  - チェックすると紙吹雪とお祝いメッセージが表示される(連続日数の節目ではバッジ獲得演出も出る)
  - 連続日数、今週の実施回数、直近8週間の履歴グリッド、週ごとのグラフを表示
  - 今月の実施回数(目標10回)の進捗バーと、目標達成の連続月数を表示
  - バッジコレクション(3日・7日・14日・30日・60日・100日の連続達成で獲得)を表示
  - 今月の実施回数で会員同士のランキングを表示(励みになる、良い意味での競争要素)
  - 自分でパスワード変更が可能

## モチベーションを上げる仕掛け

- **バッジ**: 連続日数が3日・7日・14日・30日・60日・100日に達するとバッジを獲得。マイページと管理者の会員詳細ページで見られる
- **ランキング**: 今月の実施回数で会員同士のランキングを表示(マイページ・管理者ダッシュボード両方)
- **お祝い演出**: チェックすると紙吹雪が降り、バッジの節目を達成した瞬間は専用メッセージが出る

## 特典ルール(月10回×3ヶ月継続)

- 1ヶ月に10回以上トレーニングを記録すると、その月は「目標達成」
- 目標達成の月が3ヶ月連続すると特典1回分の対象になる
- その後も継続すれば、3ヶ月ごとに繰り返し特典の対象になる(3ヶ月目、6ヶ月目、9ヶ月目…)
- 管理者ダッシュボードに「特典を渡す」ボタンが出るので、実際に手渡ししたらそれを押して記録する(会員ごとに「渡し済み◯回」が残る)
- 目標回数(10回)や継続月数(3ヶ月)を変更したい場合は `stats.js` の `MONTHLY_GOAL` と `REWARD_MONTHS` を編集してください

## データの保存場所

`data/data.json` というファイルに会員情報とチェックイン履歴が保存されます。このフォルダごとバックアップすればデータも残ります。

## 注意点

- ログインセッションはサーバーのメモリ上に保持しているため、**サーバーを再起動すると全員ログアウトされます**(小規模利用なので簡易的な作りにしています)。
- 「今日」の判定は日本時間(JST)基準です。サーバーをどこで動かしても、日付は日本時間の午前0時に切り替わります。
- 会員数20人程度の小規模利用を想定したシンプルな構成です(JSONファイル保存、常時起動の軽量サーバー)。

## 常時インターネットからアクセスできるようにしたい場合(Renderへのデプロイ)

今の状態は「自分のPCで起動している間だけ」動きます。会員が各自のスマホから常にアクセスできるようにするには、どこかのサーバーに置いて常時起動させる必要があります。ここでは無料で使える Render を使う手順を説明します。

### 手順

1. GitHubアカウントを持っていない場合は作成する(https://github.com)
2. このフォルダの中身をGitHubの新しいリポジトリにアップロードする(GitHub Desktopや `git` コマンドを使う方法があります。やり方が分からなければ相談してください)
3. https://render.com にアクセスし、GitHubアカウントでサインアップする
4. 「New +」→「Web Service」を選び、アップロードしたリポジトリを選択する
5. 設定は以下の通り
   - Runtime: `Node`
   - Build Command: 空欄のまま(何も入力しなくてOK。外部パッケージが無いため不要)
   - Start Command: `node server.js`
   - Instance Type: `Free`
6. 「Create Web Service」をクリックすると数分でデプロイされ、`https://(適当な名前).onrender.com` のようなURLが発行されます
7. そのURLをブラウザで開くと、初回は自動で管理者アカウント(`admin` / `admin123`)が作られているのでログインし、必ずパスワードを変更してください

### 無料プランの注意点

- **15分アクセスがないとスリープします。** 次にアクセスがあった時に自動的に起き上がりますが、最初の1回だけ表示に30〜60秒かかります(会員には「最初だけ少し時間がかかることがある」と伝えておくと親切です)
- **無料プランには永続ディスクが付かないため、まれにデータが消えることがあります。**(サーバーの再起動やRender側のメンテナンスのタイミングなど)これに備えて、管理者ダッシュボードに「データのバックアップ / 復元」機能を用意しています。月1回など、ダウンロードしてご自身のPCに保存しておくことをおすすめします。万が一データが消えても、保存しておいたバックアップファイルをアップロードすればすぐに復元できます。
- 上記のリスクがどうしても気になる場合は、有料プラン(月7ドル程度〜)で永続ディスクを追加するか、常時無料のOracle Cloudなど別の方法に切り替えることもできます。相談してください。
